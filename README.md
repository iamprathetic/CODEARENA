# CODEARENA 🏆

A competitive coding platform designed to help developers practice, compete, and improve their problem-solving skills. Built with **TypeScript** for reliability and scalability, CODEARENA provides both frontend and backend components to deliver a seamless coding challenge experience.

---

## 🚀 Features
- **Challenge Arena**: Solve coding problems in real-time.
- **Leaderboard**: Track rankings and progress.
- **User Profiles**: Manage submissions and achievements.
- **Frontend**: Responsive UI built with TypeScript, HTML, CSS.
- **Backend**: Secure APIs for challenge management and scoring.

## ⚡ Getting Started
### Prerequisites
- Node.js (>= 18.x)
- npm or yarn

### Installation
```bash
git clone https://github.com/iamprathetic/CODEARENA.git
cd CODEARENA
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### Backend Setup
```bash
cd backend
npm install
npm run start
```
